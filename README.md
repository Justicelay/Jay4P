### 🚀 To Launch
1. Add all images to /images/ folder
2. Add manifesto.pdf to /documents/ folder
3. Update team member names and roles in index.html (search for "[Candidate Name]")
4. Open index.html in any browser — no server needed!

### ✏️ Customisation
- Colours: Edit CSS variables in :root block (css/style.css line 1-20)
- Phone numbers: Search and replace +233245730963 and +233261612674
- Team names: Search for "[Candidate Name]" in index.html
- News articles: Edit newsData array in js/main.js
- Events: Edit event cards directly in index.html
